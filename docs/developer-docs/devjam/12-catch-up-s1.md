# DevJam XII (Season 1 Catch-Up)

[[toc]]

## Time and Duration

- Start Date: 2026-11-01
- Launch Date: 2027-01-31

## Point System

Max Earnable Points: 6, or the number of points you are away from 60, depending on which is smaller.

This table details earnable points for the Season 1 Catch-Up DevJam:

| Points |                   Set Submission                               |
| :----: | :------------------------------------------------------------: |
|   4    |                Licensed Saturn RPGs                            |
|   3    |                Standard PC-8801 games                          |
|   3    |                Licensed Saturn Games                           |
|   3    |                Atomiswave and Sega NAOMI games                 |
|   2    |                Other Licensed Games                            |
|   2    |                Non Licensed Games                              |
|   2    |                Collaborations (3-point games)                  |
|   1    |                Collaborations (2-point games)                  |
|   1    |                Subsets                                         |
|   2    |                Late Submissions (Licensed)                     |
|   1    |                Late Submissions (Others)                       |

## Quarterly Goals

This DevJam, as a catch-up period, does not have any special goals.

The list of eligible platforms is the ones featured in the first season of DevJam, as follows:

- Sega SG-1000
- Sega Saturn
- PC-8001/PC-8801
- Arcade
